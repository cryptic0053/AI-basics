# AI Fundamentals

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)

Problem sets working through the foundations of artificial intelligence — search,
knowledge representation and adversarial reasoning — implemented from scratch in
Python.

## Contents

| File | Topic |
|---|---|
| `maze.py` | Uninformed and informed search over a maze (DFS, BFS, A*) |
| `maze1.txt` – `maze3.txt` | Sample maze inputs of increasing difficulty |
| `logic.py` | Propositional logic and model checking |
| `harry.py` | Knowledge-base inference worked example |
| `clue.py` | Constraint-based deduction over the game of Cluedo |
| `mastermind.py` | Adversarial reasoning and guess optimisation |

## Running

```bash
git clone https://github.com/cryptic0053/AI-basics.git
cd AI-basics

python maze.py maze1.txt
python logic.py
```

Each script is self-contained and depends only on the standard library.
